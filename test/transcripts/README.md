# test/transcripts

Salidas de comandos por plataforma que reproduce `test/simulator`.

## Formato

Un archivo por comando. La primera línea es `# command: <comando exacto>` y el resto es la salida tal cual la imprime el equipo.

## Anonimizado

Antes de cada commit se reemplazan hostnames, IPs (usar 192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24), números de serie y cualquier secreto real. Los secretos de ejemplo (`MARKER-*`, hashes `EXAMPLE`) existen a propósito para las pruebas de enmascarado.

Las transcripciones actuales están escritas a mano siguiendo el formato público de Cisco. Se reemplazan por grabaciones anonimizadas del laboratorio al final de la Fase 1d.
