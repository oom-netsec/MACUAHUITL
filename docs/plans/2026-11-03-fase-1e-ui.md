# Fase 1e — UI de escritorio (Wails): Plan de implementación

**Goal:** Aplicación de escritorio con pantallas de bóveda, inventario, Patrol (crear, Login Test, armar, grilla en vivo) y auditoría, conectada al núcleo solo por gRPC.

**Architecture:** `ui/` es un proyecto Wails v3 dentro del módulo Go raíz. La capa Go (`ui/bridge`) solo usa `internal/ipc.Dial` y reenvía streams como eventos de Wails. El frontend React no tiene red: CSP `default-src 'self'; connect-src 'self'`.

**Tech Stack:** Wails v3.1.0, React 19 + TypeScript + Vite, TanStack Table, React Flow (reservado para la Fase 5), Vitest + Testing Library.

**Spec:** `docs/architecture/2026-11-02-macuahuitl-architecture-design.md` (§5.3, §10.4, §12). Depende de 1d.

## Global Constraints

- La UI nunca guarda secretos: los campos de contraseña se envían y se vacían; nada en `localStorage`.
- La UI arranca el servicio con `systemctl --user start macuahuitld` si el socket no responde, mediante `internal/ipc` (no ejecuta procesos desde el frontend).
- Enmascarado: la casilla aparece marcada; desmarcarla muestra aviso persistente en el trabajo (spec §12.5).
- Llaves de host cambiadas: casilla desmarcada; marcarla muestra la advertencia de exposición de credencial (spec §12.2).
- Ventana: selector de duración hasta 96 h, con texto "La llave de la bóveda estará en memoria desde ahora hasta <fecha>" antes de confirmar (spec §10.4).
- `missing_inhibitors` no vacío → aviso "La laptop podría suspenderse" antes de confirmar el armado.
- Accesibilidad: todo control alcanzable por teclado, contraste AA, estados de equipo con texto además de color.

## Review Focus

1. **Núcleo caído con la UI abierta**: la UI muestra "Núcleo desconectado" y reintenta; nunca pantalla en blanco. Test en Task 1.
2. **1 000 equipos en la grilla**: debe seguir fluida (virtualización de filas). Test en Task 3.
3. **Pegar IPs con comas, espacios, saltos de línea y rangos CIDR** en el campo de objetivos debe normalizarse igual. Test en Task 3.
4. **Cerrar la ventana con un trabajo armado** no cancela el trabajo; al reabrir se ve su estado. Test en Task 3.
5. **Contraseña maestra pegada con salto de línea final** debe recortarse solo ese salto, nunca espacios internos. Test en Task 2.
